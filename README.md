# Saleeh Usman — Premium Portfolio v2

A dependency-free, Vercel-ready portfolio for Saleeh Usman.

## Included
- Premium dark editorial visual system
- Responsive mobile-first layout
- Subtle motion and scroll reveal
- Interactive project cards
- BONPAY, NOURY, KUM SMS, Web3 Hunt, Been-Usman and Airdrop Radar concepts
- WhatsApp + Facebook contact links
- SEO/Open Graph metadata
- No build step, no npm install required

## Deploy to Vercel
Import this folder/repository into Vercel.
- Framework preset: Other
- Build command: leave blank
- Output directory: leave blank
- Install command: leave blank

The site is intentionally static so it can deploy directly from GitHub with minimal failure points.
