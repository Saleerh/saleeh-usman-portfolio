## Local preview
Open `index.html` directly, or use any static server:
```bash
python3 -m http.server 4173
```
Then visit `http://localhost:4173`.

## GitHub
Create a repository named `saleeh-usman-portfolio`, then run from this folder:
```bash
git init
git add .
git commit -m "feat: launch premium portfolio"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/saleeh-usman-portfolio.git
git push -u origin main
```

## Vercel
Import the GitHub repository into Vercel. No build command is required for this static site. Alternatively, from the project folder after installing Vercel CLI:
```bash
npm i -g vercel
vercel --prod
```
